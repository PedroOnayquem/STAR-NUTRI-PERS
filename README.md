# STAR-NUTRI

SaaS de gestao nutricional com IA para nutricionistas acompanharem pacientes, dietas, treinos, metricas e evolucao.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- FastAPI
- Supabase

## Frontend

```bash
npm install
npm run dev
```

## Backend

```bash
.\.venv\Scripts\Activate.ps1
fastapi dev backend.app.main:app
```
